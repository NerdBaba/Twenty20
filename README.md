# Twenty20

A tiny macOS app that reminds you to rest your eyes.

Every 20 minutes it covers the top of your screen for 20 seconds —
time to look 20 feet away. That's the 20-20-20 rule. Menu bar countdown,
"Break now" / "Skip" / "Pause 30 min", pauses while you're away.

## Install

Download `Twenty20.dmg` from the latest [Actions run](../../actions),
open it and drag the app to Applications. First launch: right-click → Open.

Or build it yourself: `./scripts/make_dmg.sh`.
